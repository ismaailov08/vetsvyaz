# ВетСвязь — ветеринарная телемедицина для фермеров

Веб-приложение на Django: фермер записывается к ветврачу онлайн, врач проводит видеоконсультацию,
пишет заключение и назначения, система хранит историю болезней и прививок, а цифровой двойник
по данным датчиков предупреждает о болезни животного.

## Возможности

- **Роли:** гость, фермер, ветеринарный врач, администратор района.
- **Хозяйства** по областям и районам, поголовье по видам, закреплённые врачи (связь Many-to-Many).
- **Животные** с биркой ИНЖ (KZ 0000 0000), прививками и историей болезней.
- **Консультации:** запись к врачу во всплывающем окне, видеозвонок, заключение с назначениями, печатная форма.
- **Журнал болезней:** кто болеет сейчас, частые диагнозы, история с поиском.
- **Цифровой двойник:** показания датчиков за 7 дней (температура, пульс, активность, жвачка), оценка риска, прогноз «что если».
- **Уведомления** через сигналы Django.
- **REST API** на Django REST Framework.
- **ИИ-помощник** (Google Gemini или Claude) с офлайн-режимом по правилам.

## Технологии

Python 3.12+, Django 5.2, Django REST Framework 3.18, Pillow, SQLite.

## Установка и запуск (Windows, PowerShell)

```powershell
git clone <ссылка на репозиторий> vetsvyaz
cd vetsvyaz
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo      # базовые пользователи, 8 животных, датчики
python manage.py seed_full      # 20 хозяйств в 8 областях, 373 животных, история болезней, показания за 7 дней
python manage.py runserver
```

Сайт: http://127.0.0.1:8000 · админка: http://127.0.0.1:8000/admin/ · API: http://127.0.0.1:8000/api/

Для ИИ-помощника скопируйте `.env.example` в `.env` и впишите бесплатный ключ Gemini (aistudio.google.com).

## Демо-пользователи (пароль у всех `vet12345`)

| Логин | Роль |
|---|---|
| admin | администратор |
| farmer, farmer2 … farmer20 | фермеры (хозяйства) |
| vet, vet2, vet3 | ветврачи: КРС, МРС, лошади и верблюды |

## Структура проекта

```
vetsvyaz/
├── config/          настройки, главный urls.py, wsgi/asgi
├── accounts/        пользователи, роли, профили фермера и врача, регистрация, права
├── farms/           хозяйства, животные, прививки, журнал болезней, главная, команды seed_*
├── consultations/   консультации, назначения, заключения, сигналы уведомлений
├── notifications/   уведомления (колокольчик)
├── twin/            цифровой двойник: датчики, показания, оценка риска, прогноз
├── assistant/       ИИ-помощник
├── api/             REST API: сериализаторы, ViewSet, router
├── templates/       шаблоны (base.html + страницы приложений)
├── static/          CSS и JavaScript
├── docs/            ER-диаграмма (PNG) и схема для dbdiagram.io (DBML)
├── manage.py
└── requirements.txt
```

## REST API

| Метод и адрес | Описание |
|---|---|
| GET /api/animals/ | животные, доступные пользователю |
| GET, POST /api/consultations/ | консультации, запись к врачу |
| GET, POST /api/readings/ | показания датчиков (запись — служебная учётная запись) |
